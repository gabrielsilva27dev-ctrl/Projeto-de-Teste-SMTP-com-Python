# Projeto-de-Teste-SMTP-com-Python
ste projeto foi desenvolvido para estudar conceitos de Python relacionados a:  Variáveis de ambiente;  Envio de e-mails utilizando SMTP;  Manipulação de mensagens com MIMEText;  Tratamento de exceções;  Execução de tarefas temporizadas com Timer.  O projeto utiliza o servidor SMTP do Gmail para realizar testes de autenticação e envio de mensagens.
